# Desafío Bíblico — Gracia Camp

Proyecto de dinámicas bíblicas para jóvenes CBG.

## Juegos previstos

1. Palabras desordenadas.
2. Preguntas bíblicas.
3. Ahorcado bíblico con personaje 3D.
4. ¿Quién soy? / ¿Qué lugar es? con pistas.
